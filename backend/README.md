## 브랜치 네이밍 규칙

Backend 작업 시에는 `feature/back-*` 브랜치를 사용합니다.

전체 브랜치 컨벤션:

- `feature/back-*` — backend 작업 (본 영역)
- `feature/front-*` — frontend 작업
- `feature/ai-*` — ai 작업

모든 feature 브랜치는 `develop` 브랜치를 기준으로 생성하고, 작업 완료 후 `develop`으로 PR을 올립니다.
